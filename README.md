# 🌴 HH Goa 2026 Builder Card Generator

A modern web application built for the **Hacker House Goa 2026** shortlisting challenge.

Generate beautiful **HH Goa-themed Builder Cards** and **Profile Frames** by simply uploading your photo. Download your personalized card or share it with a single click.

## 🚀 Live Demo

🔗 https://hh-goa-card-generator-gules.vercel.app/

## ✨ Features

- 📸 Upload JPG, PNG (and compatible image formats)
- ⚡ Instant live preview
- 🪪 HH Goa themed Builder Card
- 👤 HH Goa Profile Frame
- 🎨 Automatic Builder Title generation
- ⬇️ Download high-quality PNG
- 🐦 One-click sharing to X
- 💼 Share to LinkedIn
- 📷 Instagram-ready sharing flow
- ☁️ Image upload using Vercel Blob
- 📱 Fully responsive design

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rizzhub3118/hh-goa-card-generator.git
```

Go to the project

```bash
cd hh-goa-card-generator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 🌟 How it Works

1. Upload your photo.
2. Choose between Builder Card or Profile Frame.
3. Preview updates instantly.
4. Download the generated image.
5. Share it directly to your favorite social platform.
